# FRIDAY AI

A personal AI assistant built with Modern C++23, inspired by Iron Man's F.R.I.D.A.Y.

> **Note:** This is an independent open-source project inspired by a fictional AI. It is not affiliated with Marvel, Disney, or any related entities.

## Features

### Currently Implemented (v0.1.0)
- Interactive command-line interface
- Case-insensitive command parsing
- Current date and time display
- Local note-taking system (save, list, clear)
- Configurable assistant name and settings
- Structured modular architecture
- Built with C++23 (`std::format`, `std::chrono`, `std::filesystem`)

### Planned
- AI conversation (cloud and local model support)
- Voice interaction (speech-to-text and text-to-speech)
- Permission-controlled desktop automation
- Conversation memory and personalization
- Graphical user interface
